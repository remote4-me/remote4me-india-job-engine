# Source and access notice

This repository is intended for public-job discovery and official-source verification.

Use every external source according to its current terms, robots directives, attribution requirements, API terms and rate limits.

Sources used by v4 include OnJob, Jobicy, Dev Global Jobs, RemoteJobs.org, YubHub and We Work Remotely. Their current public documentation permits public-feed/API integrations under different attribution/fair-use conditions. Review the current source terms before changing the integration or displaying source data on remote4.me.

The project intentionally avoids:
- CAPTCHA solving
- login bypass
- paywall bypass
- anti-bot evasion
- IP-block evasion
- private/authenticated data

Internet Archive / Wayback is used as a historical discovery source, not as proof that a job is currently open.

A third-party source URL is not automatically treated as an official employer URL. The resolver must find a current public employer/ATS URL before a job enters `VERIFIED_JOBS`.
